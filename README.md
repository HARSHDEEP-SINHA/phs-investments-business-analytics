## Project Overview

This project simulates the analytics workflow of a mutual fund distribution company using a realistic synthetic dataset.

The objective is to demonstrate how Business Analysts use SQL, Python, Excel and Power BI to generate business insights from investment data.

---

## Business Problem

Investment firms generate thousands of transactions every month.

Business leaders require dashboards to answer questions such as

- How fast is AUM growing?
- Which cities contribute the highest investments?
- Which mutual funds generate maximum revenue?
- What is the monthly SIP growth?
- Which customer segments are most valuable?

This project answers these questions.
